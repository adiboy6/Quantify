# Frontend Setup
## Setup Node
Install latest Node.js. Instructions can be found here - https://nodejs.org/en/download/package-manager

## Setup Package Manager
For our project we will use PNPM for managing packages.
Install PNPM using the following command. This will install PNPM globally on the system.
```npm install -g pnpm```

## Install dependencies
```
cd dashboard
cd frontend
pnpm install
```

This will install all the dependencies.

## Start the dev server
`pnpm run dev` to start the development server.
